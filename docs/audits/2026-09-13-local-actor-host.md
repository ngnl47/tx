# I3f：提取私有本地实体宿主

## 原因与边界

邮箱、激活和生命周期实现此前位于 `internal/actortrial`，正式 framework 若直接引用，会连同 NATS 试验连接及比较夹具一并依赖。现将唯一实现及其测试迁到 `internal/actorhost`，试验适配通过类型别名继续复用，不复制运行时，不新增 game 侧 SPI 或后端开关。

例如，Agent 的直连 gRPC 请求与 Actor 的 NATS 请求仍投递到同一个 Runtime；加载权威校验、容量预留和卸载前回调仍由这个宿主管理。传输提交响应回调仍在 worker 内完成并纳入排水。

Future 的完成、已完成信号和带响应提交成为私有包之间的协作入口。状态探测补充当前队列长度供既有跨包测试观察；仅探测时读取，不在生产逐消息路径增加采集计数。取消只结束等待，不取消已接受业务；完成信号选中后直接读取已完成结果，避免第二次上下文取消选择改变结果。

原试验 Placement 与测试随宿主保留，未升级为正式稳定归属策略；它仍不承诺 Watch 期间唯一激活。稳定归属继续由 Discovery L2 负责。正式 framework 仍使用 ProtoActor，Kind、共享 RPC 注册和启动顺序接线尚未完成。
