# 直接 Mongo 写回与 WAL 移除

本轮在现有未提交改动上串行执行，不提交 Git，不引入 MQ。

## 持久化边界

- Procedure 提交仍只提交内存，WriteBackManager 成功刷盘后才清理变更。
- Mongo 单次条件更新同时检查内部所有权代次和写入序号；迟到的旧写入不能覆盖新值。
- 所有权及序号属于框架内部存储元数据，不进入业务 GD，不要求逐 GD Binding。
- 直接写入采用 majority 和 journal 确认；失败保留变更，关闭沿用有限重试。
- 世界槽位归属与准入仍由项目处理，存储层只执行所有权声明和条件写入。
